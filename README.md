# 토스증권 배당·매매 통합 수익 대시보드

국내주식(원화 KRW)과 미국주식(달러 USD · 입금시점 확정환율 원화 환산 지원)의 **매매 손익 + 실수령 배당금**을 종목별·연도별로 한눈에 합산해 볼 수 있는 **100% 조회·열람 전용** 로컬 웹 대시보드입니다.

* **매수·매도 주문 기능 없음**: 계좌 잔고·체결·배당 내역 열람만 수행하며 주문 관련 기능은 코드에 포함되어 있지 않습니다.
* **로컬 PC 전용 보관**: 등록한 거래내역서 PDF와 원장 데이터베이스(`data/portfolio.db`)는 외부 전송 없이 내 컴퓨터 내부에만 저장됩니다.
* **추가 패키지 설치 불필요**: 별도의 외부 라이브러리(`pip`) 설치 없이 기본 Python 3.9 이상 표준 환경만으로 **Windows**와 **macOS**에서 모두 동일하게 동작합니다.

## 1. AI(제미나이 · 클로드 · 챗GPT)에게 자동 설치·실행 맡기는 방법

복잡한 설정 없이 내 PC와 연동된 AI 도구(제미나이, 클로드, 챗GPT 등)에 **아래 문구를 그대로 복사해 붙여넣으면** 운영체제(Windows · Mac)에 맞춰 알아서 내려받고 대시보드까지 실행해 줍니다(GitHub 회원가입·로그인 불필요).

```text
GitHub 공개 저장소(ppujigi-byte/toss-dividend-dashboard)를 내 컴퓨터 작업 폴더에 내려받아서 README.md 하단의 'AI 에이전트 자동 세팅 지침'대로 환경을 확인하고 대시보드를 바로 실행해 줘.
```

> 만약 웹 전용 AI 채팅창처럼 내 PC 폴더에 직접 접근하지 못하는 환경이라면, 이 페이지 우측 상단의 초록색 **`<> Code` → `Download ZIP`**으로 압축만 푼 뒤 로컬 폴더 연동 기능이 있는 AI에 해당 폴더를 지정해 요청하거나 아래 **3번 직접 실행 방법**을 따라 실행하세요.

## 2. 주요 기능

* **거래내역서 PDF 확정 원장 자동 구축**: 토스증권에서 발급받은 거래내역서 PDF를 등록하면 매수·매도, 타사대체입고, 주식분할·병합, 원화·외화 배당 입금, 외화세금환급·배당세 재정산 내역을 자동 분석해 원장을 구축합니다.
* **세후 / 세전 전환 및 미국 배당 원화 환산**: 배당소득세·제세금·수수료를 차감한 실질 순수익과 세전 수익을 스위치 하나로 비교하고, 미국 배당금을 실제 입금 당시 적용 환율 기준 원화로 전환해 확인할 수 있습니다.
* **연도별 배당 성장 그래프**: 국내·미국·통합 원화 기준 연도별 배당 추이, 전년 대비 증감률(YoY), 월평균 배당금을 막대그래프와 표로 제공합니다.
* **타 증권사 배당 합산 지원**: 이관 전 다른 증권사에서 수령한 배당금을 종목별 또는 연도별(2019년~)로 입력해 통합 수익률을 계산할 수 있습니다.
* **실시간 시세 및 증분 동기화(선택)**: 보유 종목의 현재가를 새로고침해 평가손익을 즉시 재계산하며, 토스증권 Open API 조회 권한을 연결하면 PDF 기준일 이후의 신규 체결·배당 내역만 중복 없이 이어서 반영합니다.

## 3. 직접 내려받아 실행하는 방법 (Windows · Mac 공통)

### 3-1. 파일 내려받기 및 사전 준비
1. 이 GitHub 페이지 우측 상단의 초록색 **`<> Code` → `Download ZIP`**을 눌러 원하는 폴더에 압축을 풉니다.
2. **Windows** 사용자는 PC에 Python 3.9 이상이 설치되어 있어야 합니다(**macOS**는 기본 Python 3 또는 별도 설치된 Python 3.9 이상에서 바로 동작합니다).

### 3-2. 프로그램 실행
* **Windows 사용자**: 압축을 푼 폴더 안의 **`실행하기.py`** 파일을 실행하거나, 명령 프롬프트(터미널)에서 아래 명령어를 입력합니다.
  ```bash
  python 실행하기.py
  ```
* **Mac 사용자**: 폴더 안의 **`실행하기_Mac.command`** 파일을 실행하거나, 터미널에서 아래 명령어를 입력합니다.
  ```bash
  python3 실행하기.py
  ```
* 서버가 켜지면 기본 웹 브라우저에서 대시보드 화면(`127.0.0.1:8765`)이 자동으로 열립니다. 사용을 마친 뒤에는 실행된 콘솔(터미널) 창을 닫거나 `Ctrl + C`를 누르면 종료됩니다.

## 4. 처음 시작하기: 토스증권 거래내역서 PDF 등록 안내

과거 전체 매수·매도 평단가와 실제 입금된 배당금(입금환율·세금재정산 포함)을 정확히 합산하려면 **토스증권에서 거래내역서를 반드시 PDF 파일로 발급**받아 업로드해야 합니다.

1. **토스 앱** 실행 → 하단 **[증권]** 탭 → 오른쪽 위 **전체 메뉴(≡)** 선택
2. **[설정] → [계좌] → [증명서 발급하기] → [거래내역서]** 진입 *(또는 고객센터 → 증명서 발급 필요해요 → 거래내역서)*
3. 거래종류 **[전체]**, 통화 **[전체(원화+외화)]**로 선택하고 조회 기간을 지정해 **비밀번호 없는 일반 PDF 파일**로 저장한 뒤 PC로 옮깁니다.
4. 대시보드 첫 화면의 **`📄 PDF 업로드 · 발급방법`** 버튼(또는 상단 **`📄 PDF 등록 · 관리`**)을 눌러 PDF 파일들을 끌어다 놓으면 즉시 원장이 생성됩니다.
   * 거래 기간이 길어 1년 단위로 여러 개의 PDF로 나누어 받아도 **한꺼번에 선택해 업로드**할 수 있으며, 기간이 일부 겹쳐도 중복 없이 자동 합산됩니다.
   * Open API를 연결하지 않아도 첫 화면 하단의 **`API 연결 없이 PDF 원장 대시보드 바로 열기 →`** 버튼을 누르면 전체 수익·배당 대시보드와 **`⚡ 현재가 새로고침`** 기능을 바로 사용할 수 있습니다.

## 5. 토스증권 Open API 증분 연동 (선택 사항)

PDF 기준일 이후 발생하는 신규 매매 체결과 실시간 잔고를 자동으로 이어 붙이려면 토스증권 Open API를 연결해 사용할 수 있습니다.

1. 토스증권 PC 웹(WTS) → **설정 → Open API → 허용 IP 관리** 메뉴에서 현재 사용 중인 인터넷의 공인 IP를 등록합니다.
2. 대시보드 설정 화면에서 발급받은 조회용 API 정보를 등록하고 본인만 아는 **6자리 숫자 PIN**을 지정하면 브라우저 암호화(`AES-256-GCM`)를 거쳐 내 PC(`data/encrypted_config.json`)에만 안전하게 저장됩니다.
3. 이후 상단의 **`↻ 토스 API 증분 동기화`**, **`💸 이후 배당 갱신`**, **`📜 동기화 로그`** 버튼으로 최신 내역과 상세 반영 이력을 확인할 수 있습니다.

## 7. AI 에이전트 자동 세팅 지침 (For AI Assistants: Gemini, Claude, ChatGPT)

이 저장소(`ppujigi-byte/toss-dividend-dashboard`)는 **공개(Public) 저장소**입니다. 사용자가 저장소 주소나 로컬 폴더를 제공하고 설치·실행을 요청하면 추가 질문 없이 아래 절차를 순서대로 수행하세요.

1. **외부 패키지 설치 생략**: 이 프로젝트는 Python 3.9 이상 표준 라이브러리(`http.server`, `sqlite3`, `zlib`, `urllib`, `zoneinfo` 등)만 사용하므로 `pip install`이나 가상환경(`venv`) 생성이 전혀 필요하지 않습니다.
2. **Python 3.9+ 확인**:
   * **macOS**: `python3 --version`으로 Python 3.9 이상 여부를 확인합니다.
   * **Windows**: `python --version` 또는 `py -3 --version`으로 Python 3.9 이상 여부를 확인합니다. 미설치 상태라면 사용자에게 Python 3 공식 설치부터 안내합니다.
3. **공개 저장소 자동 다운로드 (`ppujigi-byte/toss-dividend-dashboard`)**:
   * 이미 로컬 폴더에 `server.py`와 `실행하기.py`가 존재하면 해당 폴더를 그대로 사용합니다.
   * 원격에서 내려받아야 한다면 사용자의 작업 폴더에 GitHub 공개 저장소 `ppujigi-byte/toss-dividend-dashboard`를 `git clone`으로 내려받습니다.
   * 만약 사용자 PC(특히 Windows)에 `git`이 설치되어 있지 않다면, Git을 따로 설치하지 말고 GitHub 저장소 `ppujigi-byte/toss-dividend-dashboard`의 `archive/refs/heads/main.zip` 압축 아카이브를 Python 표준 라이브러리(`urllib.request`, `zipfile`)로 바로 내려받아 압축을 해제합니다.
4. **대시보드 서버 백그라운드 기동 및 브라우저 열기**:
   * 내려받은 프로젝트 루트 폴더(`server.py`가 있는 경로)에서 아래 명령어를 백그라운드로 실행합니다(기본 포트 `8765`, 이미 실행 중이면 기존 서버 재사용).
     * **macOS**: `python3 실행하기.py`
     * **Windows**: `python 실행하기.py` (또는 `py -3 실행하기.py`)
5. **실행 완료 후 사용자 안내**:
   * 웹 브라우저에서 로컬 대시보드(`127.0.0.1:8765`)가 정상적으로 열렸는지 확인합니다.
   * 사용자에게 *"설치와 실행이 완료되었습니다! 열린 화면에서 `📄 PDF 업로드 · 발급방법` 버튼을 눌러 토스 앱에서 발급받은 거래내역서 PDF를 끌어다 놓으면 바로 전체 배당·매매 대시보드를 볼 수 있습니다"*라고 안내합니다.
