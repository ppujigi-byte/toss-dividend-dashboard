📄 토스증권 거래내역서 PDF 등록 · 원장 관리 · 백업

📌 토스증권에서 '거래내역서 PDF' 발급받아 올리는 방법 토스 공식 증명서 안내 ↗

토스증권 Open API는 최근 내역 위주로 제공되므로, 과거 전체 매수·매도 단가와 타사대체입고, 실제 입금된 배당금(입금환율·세금환급·재정산 포함)을 정확히 계산하려면 토스증권에서 거래내역서를 반드시 PDF 파일로 발급받아 업로드해야 합니다.

  1. 토스 앱 실행 → 하단 [증권] 탭 → 오른쪽 위 전체 메뉴(≡) 선택
  2. [설정] → [계좌] → [증명서 발급하기] → [거래내역서] 진입 (또는 우측 상단 [고객센터] → [증명서 발급 필요해요] → [거래내역서])
  3. 거래종류 [전체], 통화 [전체(원화+외화)]로 선택하고 조회 기간을 지정해 PDF 파일로 저장 후 PC로 전송 (카카오톡 나에게 보내기 · 이메일 등)
💡 여러 개 파일 동시 업로드 OK: 거래 기간이 길어 1년 단위로 여러 개의 PDF로 나누어 발급받아도 한꺼번에 선택해 올리시면 됩니다. 기간이 일부 겹쳐도 발급번호 기준으로 중복 없이 자동 합산되며, 업로드한 PDF는 외부 전송 없이 내 PC(pdfs/)에만 보관됩니다.
